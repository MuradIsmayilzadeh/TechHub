# TechHub

An online electronics store (Azerbaijani UI), built with Next.js 14, Tailwind CSS and MongoDB.

## Features
- Product catalogue with search and category filters
- Product detail and order (checkout) pages
- About and Contact pages
- `/api/posts` endpoint backed by MongoDB, with built-in sample products when no database is configured

## Getting started
```bash
npm install
cp .env.example .env.local   # optional: add MONGODB_URI
npm run dev
```
Open http://localhost:3000.
